# Johannesburg Community Energy

A plain HTML, CSS, and JavaScript dashboard estimating solar and wind generation for a 50-home community in Johannesburg, South Africa.

## Run locally

Open `index.html` in a browser. The dashboard loads hourly weather data from Open-Meteo and uses Chart.js from its CDN, so an internet connection is required.

## Host with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, then save. The site will be available at:

`https://MbulaheniPM.github.io/test-project/`

The dashboard estimates generation from forecast weather values. It does not yet simulate battery charging or discharge.
